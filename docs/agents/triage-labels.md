# Triage labels

| Role                               | Label             |
| ---------------------------------- | ----------------- |
| New work that needs classification | `needs-triage`    |
| Work blocked on a question         | `needs-info`      |
| Work an agent can start            | `ready-for-agent` |
| Work that needs a person           | `ready-for-human` |
| Work that will not continue        | `wontfix`         |
